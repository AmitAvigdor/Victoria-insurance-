# Victoria branding — 7 October 2026

The supplied JPG is preserved verbatim as `public/branding/victoria-original.jpg`.
Login and password recovery show its central shield, Hebrew wordmark and tagline
through a CSS viewport. The application uses deep navy (`#0d2e5b`), blue
(`#113c73`) and gold (`#d6a348`), with pale backgrounds and separate status colors.

## Image assets

The built-in image generation tool was used in edit mode for the small raster
derivatives. These are derived illustrations rather than pixel-identical crops.
The prompt set requested:

1. Extract the central shield, rising arrow, chart and lock from the supplied
   logo. Preserve the blue and gold identity; remove all lettering, the pale
   circular backdrop, ground shadow and separate right-hand icon. Use actual
   transparency and padding for a small application mark.
2. Create a square application icon from that mark, on a full deep navy canvas,
   with the exact white Hebrew wordmark “ויקטוריה”. Keep the shield centered,
   legible at small sizes, and leave corner rounding to the operating system.
3. Adapt the application icon for maskable presentation: preserve the shield,
   wordmark, colors and navy canvas; reduce and center the artwork with generous
   padding so it stays within the central circular safe area.

Selected outputs were copied into the project and resized with macOS `sips`:

- `public/branding/victoria-mark.png` — transparent mark, 256 × 256.
- `public/branding/victoria-favicon.png` — browser icon, 48 × 48.
- `public/branding/victoria-apple-touch-icon.png` — iPhone icon, 180 × 180.
- `public/branding/victoria-icon-192.png` — application icon, 192 × 192.
- `public/branding/victoria-icon-512.png` — application icon, 512 × 512.
- `public/branding/victoria-icon-maskable-512.png` — maskable icon, 512 × 512.

All assets are served locally; no external image hosts were added. Authentication,
database permissions and security headers were not changed.
